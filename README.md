# Тема роботи

Розробка системи управління студентами з аналізом даних та реалізацією алгоритмів сортування.

---

# Мета роботи

Ознайомитися з роботою масивів об'єктів у JavaScript, реалізувати алгоритми сортування Bubble Sort та Quick Sort, виконати аналіз їх продуктивності та створити систему для роботи з даними студентів.

---

# Функціональні можливості

* Перегляд списку студентів.
* Фільтрація студентів за факультетом та мінімальним GPA.
* Сортування студентів за:

  * ім'ям;
  * віком;
  * GPA.
* Виведення статистики:

  * кількість студентів;
  * середній GPA;
  * ТОП-3 студенти;
  * розподіл студентів по факультетах.
* Порівняння алгоритмів Bubble Sort та Quick Sort.
* Підрахунок кількості порівнянь для кожного алгоритму.
* Вимірювання часу виконання алгоритмів на масивах:

  * 100 елементів;
  * 1000 елементів;
  * 5000 елементів.

# Реалізовані алгоритми

## Bubble Sort

Алгоритм послідовно порівнює сусідні елементи та міняє їх місцями при необхідності.

## Quick Sort

Алгоритм використовує опорний елемент (pivot) та рекурсивно розділяє масив на частини.

# Висновок

У ході виконання практичної роботи було створено систему управління студентами з можливістю фільтрації, сортування та аналізу даних. Було реалізовано та досліджено алгоритми Bubble Sort і Quick Sort. Результати показали, що Quick Sort працює значно швидше на великих масивах даних, ніж Bubble Sort.
